# Cloudflare Sandbox Migration Spec

> Migration from Modal to Cloudflare Sandbox SDK for Open-Inspect

## Overview

Replace Modal sandbox infrastructure with Cloudflare Sandbox SDK. This is a clean fork - no
backwards compatibility with Modal required.

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                  Control Plane Worker                        │
│                                                              │
│  ┌──────────────┐         ┌──────────────────────────────┐  │
│  │  SessionDO   │ ──────► │  Sandbox (Durable Object)    │  │
│  │              │         │  ┌────────────────────────┐  │  │
│  │  - Sessions  │ ◄────── │  │  Cloudflare Container  │  │  │
│  │  - Messages  │   WS    │  │                        │  │  │
│  │  - Events    │         │  │  supervisor.ts         │  │  │
│  │  - Prompts   │         │  │       ↓                │  │  │
│  └──────────────┘         │  │  bridge.ts ←→ OpenCode │  │  │
│                           │  └────────────────────────┘  │  │
│                           └──────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

### Key Changes from Modal

| Aspect           | Modal                            | Cloudflare                           |
| ---------------- | -------------------------------- | ------------------------------------ |
| Sandbox creation | HTTP API to Modal service        | Durable Object binding (same Worker) |
| Container image  | Custom `base_image` Python build | `cloudflare/sandbox:0.7.0-opencode`  |
| Supervisor       | Python `entrypoint.py`           | TypeScript `supervisor.ts`           |
| Bridge           | Python `bridge.py`               | TypeScript `bridge.ts`               |
| Snapshot/restore | Native `snapshot_filesystem()`   | Skipped for MVP                      |
| Authentication   | HMAC tokens for HTTP API         | Not needed (same Worker)             |
| Auto-sleep       | Manual timeout                   | Built-in `sleepAfter: "1h"`          |

## Configuration

### Instance Type

- **Type**: `standard-2` (1 vCPU, 6GB RAM, 12GB disk)
- **Sleep**: `sleepAfter: "1h"` (1 hour of inactivity)

### Environment Variables (passed to sandbox at runtime)

| Variable            | Source                 | Purpose                           |
| ------------------- | ---------------------- | --------------------------------- |
| `SANDBOX_ID`        | Generated by SessionDO | Unique sandbox identifier         |
| `SESSION_ID`        | From session           | For WebSocket routing             |
| `CONTROL_PLANE_URL` | Worker URL             | WebSocket endpoint for bridge     |
| `REPO_OWNER`        | Session config         | GitHub repo owner                 |
| `REPO_NAME`         | Session config         | GitHub repo name                  |
| `GITHUB_APP_TOKEN`  | Generated fresh        | Git clone/push authentication     |
| `ANTHROPIC_API_KEY` | Cloudflare Secrets     | LLM API key (OpenCode reads this) |
| `OPENAI_API_KEY`    | Cloudflare Secrets     | Optional LLM API key              |
| `SESSION_CONFIG`    | JSON blob              | Full session configuration        |

## Component Specifications

### 1. supervisor.ts

Port of `packages/modal-infra/src/sandbox/entrypoint.py`

**Responsibilities:**

- Run as PID 1 inside container
- Perform git clone/sync on startup
- Start OpenCode server and wait for health
- Start bridge process
- Monitor processes, restart on crash with exponential backoff
- Handle SIGTERM/SIGINT for graceful shutdown

**Key Functions:**

```typescript
class SandboxSupervisor {
  // Configuration
  OPENCODE_PORT = 4096;
  HEALTH_CHECK_TIMEOUT = 30_000;
  MAX_RESTARTS = 5;

  // Lifecycle
  async performGitSync(): Promise<boolean>;
  async startOpenCode(): Promise<void>;
  async startBridge(): Promise<void>;
  async monitorProcesses(): Promise<void>;
  async shutdown(): Promise<void>;
}
```

### 2. bridge.ts

Port of `packages/modal-infra/src/sandbox/bridge.py`

**Responsibilities:**

- WebSocket connection to SessionDO with reconnection logic
- Heartbeat loop (30s interval)
- Stream OpenCode SSE events → SessionDO
- Handle commands: prompt, stop, push, shutdown
- Configure git identity per prompt author

**Key Functions:**

```typescript
class AgentBridge {
  HEARTBEAT_INTERVAL = 30_000;
  RECONNECT_BACKOFF_BASE = 2;
  RECONNECT_MAX_DELAY = 60_000;

  async run(): Promise<void>;
  async handlePrompt(cmd: PromptCommand): Promise<void>;
  async handlePush(cmd: PushCommand): Promise<void>;
  async streamOpenCodeResponse(messageId: string, content: string): AsyncGenerator<Event>;
}
```

### 3. opencode-id.ts

Port of `OpenCodeIdentifier` class from bridge.py

**Purpose:** Generate OpenCode-compatible ascending message IDs

**Format:** `{prefix}_{timestamp_hex}{random_base62}`

### 4. Control Plane Changes

**wrangler.toml additions:**

```toml
[[durable_objects.bindings]]
name = "Sandbox"
class_name = "Sandbox"

[[containers]]
class_name = "Sandbox"
image = "./packages/sandbox/Dockerfile"
instance_type = "standard-2"
```

**SessionDO changes:**

- Remove `createModalClient()` calls
- Add `getSandbox(env.Sandbox, sandboxId)`
- Spawn sandbox via `sandbox.exec()` or `sandbox.startProcess()`
- Sandbox WebSocket connects back to SessionDO

## WebSocket Communication

### SessionDO ↔ Bridge Protocol

**Bridge → SessionDO (events):**

```typescript
type BridgeEvent =
  | { type: "ready"; sandboxId: string; opencodeSessionId?: string }
  | { type: "heartbeat"; sandboxId: string; status: string; timestamp: number }
  | { type: "token"; content: string; messageId: string }
  | {
      type: "tool_call";
      tool: string;
      args: object;
      callId: string;
      status: string;
      messageId: string;
    }
  | { type: "step_start" | "step_finish"; messageId: string }
  | { type: "execution_complete"; messageId: string; success: boolean; error?: string }
  | { type: "push_complete" | "push_error"; branchName: string; error?: string };
```

**SessionDO → Bridge (commands):**

```typescript
type SessionCommand =
  | { type: "prompt"; messageId: string; content: string; model?: string; author?: AuthorInfo }
  | { type: "stop" }
  | { type: "push"; branchName: string; githubToken: string }
  | { type: "snapshot" }
  | { type: "shutdown" };
```

### Authentication

Since SessionDO and Sandbox are in the same Worker:

- **No external HTTP API** = no HMAC tokens needed
- Bridge WebSocket connects to SessionDO internally
- SessionDO validates sandbox ID matches expected

## Dockerfile

```dockerfile
FROM docker.io/cloudflare/sandbox:0.7.0-opencode

# The -opencode variant already includes:
# - Node.js 20 LTS
# - OpenCode CLI
# - git, curl, etc.

# Install additional dependencies if needed
RUN npm install -g typescript

# Copy compiled supervisor and bridge
WORKDIR /app
COPY dist/ ./

# Copy OpenCode plugin for PR creation
COPY inspect-plugin.js ./

ENTRYPOINT ["/sandbox"]
CMD ["node", "/app/supervisor.js"]
```

## Risk Mitigation

| Risk                              | Mitigation                                                     |
| --------------------------------- | -------------------------------------------------------------- |
| OpenCode base image missing tools | Test image locally first; add to Dockerfile if needed          |
| WebSocket connection issues       | Keep reconnection logic from Python bridge                     |
| Large repo clone times            | Consider shallow clone (`--depth 1`) - already in current code |
| Sandbox startup latency           | Monitor cold start times; consider warm pools later            |
| No snapshot = lost work           | Set high sleepAfter (1h); document limitation                  |

## Success Criteria

1. Can create a session and spawn a Cloudflare sandbox
2. Can send prompts and receive streamed responses
3. Can create commits with correct author attribution
4. Can create pull requests
5. WebSocket reconnection works after bridge restart
6. Sandbox auto-sleeps after 1 hour of inactivity
7. No Modal dependencies remain in codebase
